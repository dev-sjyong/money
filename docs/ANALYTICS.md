# 통계 고도화 — Plan → Do → Check → Act

## Plan
- 사용자는 지출 분석과 자산/부채를 균형 있게 요청.
- 통계 요약: 월·3/6/12개월·직접 기간, 직전 동일 길이 기간 비교(월 단위는 이전 동일 개월 수), 수입/지출/수지/순자산, 월별 추이.
- 상위/개별 지출 항목 분석, 이전 기간 비교, 항목 선택 → 해당 분개 금액 기준 거래 상세, 페이지 처리와 CSV 내보내기.
- 자산 보고서: 기준일, 전월 말 비교, 계정별 변화량. 순자산: 6/12/24개월, 자산/부채/순자산 지표 선택 및 월별 증감.
- 이체/원금 상환은 수입·지출에서 제외. 환불은 지출 감소. 계층 중복 합산 방지, 보관 계정 포함, BIGINT 문자열 금액 유지.
- 시세/개인회생 예정액을 원장 통계에 자동 혼합하지 않음. 통계는 실제 저장된 원장 기준.
- 기존 SQL 변경 없음. 기존 PR은 main 병합 확인, 별도 기능 브랜치.

## Check
단위: 비교 날짜/윤년, 부분 기간, 환불, 분할 분개, 계층, 이전에만 발생한 항목, 이체 제외, 기준일, 정밀도, CSV 이스케이프. UI: 기간/필터/상세/다운로드/날짜/모바일/가계부 전환. 빌드/타입과 기존 UI 회귀.

## 결과
- `통계 한눈에` 신규 메뉴 구현: 월/3/6/12개월/직접 기간, 이전 기간 대비 증감, 수지율, 기간 말 순자산, 일평균 지출, 수입·지출 추이.
- 상위/개별 지출 계정과 비중, 환불 내역, 항목별 거래 상세/20건 페이지 처리, CSV 내보내기. 완전 환불로 순지출 0인 항목과 이전 기간에만 존재한 항목도 확인 가능.
- 자산·부채 기준일/전월 말 비교/0잔액 숨기기/CSV, 순자산 6/12/24개월/지표 선택/월별 증감/CSV 구현.
- 기간 범위는 1902년 이후 최대 732일. 월 단위 비교는 직전 동일 개월 수, 직접 선택은 직전 동일 일수. 현재 월 전체 선택 시 미래 날짜로 기록한 거래도 포함됨을 표시.
- 금액은 bigint로 집계하고 비율만 계산. 비율 기준이 0 이하인 경우 미표시. 지출 비중은 양수 순지출 합계 기준, 환불 초과 항목 별도 표시.
- CSV 셀 따옴표/줄바꿈 처리 및 사용자 문자열의 수식 시작 문자 방어. 다운로드에는 현재 상세 필터의 모든 페이지가 포함된다.
- `npm test`: 기존 11 + 신규 5 = 16개 통과.
- 타입검사와 프로덕션 빌드 통과.
- Chromium 4개 시나리오 통과: 통계 기간/비교/환불/분할 거래/CSV 다운로드/페이지 이동/자산 날짜/추이/320px·390px/다른 가계부로 전환, 기존 거래/인증/개인회생 일정 회귀.
- 데스크톱·모바일 화면 생성 및 육안 확인. 모바일 표의 세로 글자 줄바꿈은 표 내부 가로 스크롤로 개선.
- 브라우저는 실제 앱과 Supabase HTTP fixture 사용. 운영 원격 통합 테스트·운영 배포는 수행하지 않았다. DB/RPC를 변경하지 않아 이번 작업에서 DB 테스트를 재실행하지 않았다.

## Act / 반영
추가 migration 없음. PR 병합으로 Vercel 배포 후 메뉴의 통계 한눈에에서 확인한다. 원장 전체를 클라이언트에서 집계하는 기존 구조를 유지하므로 대용량 서버 집계/페이지 조회는 별도 과제다. 개인회생 일정의 납부액은 거래 원장과 별도이며 통계에 자동 포함되지 않는다.
