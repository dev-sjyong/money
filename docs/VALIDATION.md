## 실제 PostgreSQL 검증 상세

`tests/bootstrap.sql`의 auth.users/auth.uid 스텁과 authenticated/anon PostgreSQL 역할을 사용했습니다. 단순 SQL 문자열 검사가 아닌 실제 query/function/constraint 실행입니다.

- 가계부 생성 및 기본 계정, 기초 자산/부채, 중복 기초등록 차단.
- 5가지 회계 예시와 거래별 균형, 이체/카드대금 비용 제외.
- 거래 원자적 수정, stale 수정 거부, 삭제 시 계산 잔액 복원.
- 불균형, 0, 소수 금액, 계정 순환, 계정 유형 변경 차단.
- 분개 INSERT 중 제약 실패 시 transaction까지 전체 롤백 확인.
- JSON 금액 문자열 및 9,007,199,254,740,993원 정확한 보존.
- 요청 UUID 중복 저장 차단.
- accounts/transactions/transaction_lines/budgets/view/snapshot 타 가계부 격리.
- 다른 가계부 UUID·계정 ID로 RPC 조작 차단.
- 테이블 직접 INSERT/DELETE, 익명 조회/RPC 차단.
- MEMBER 계정/설정/초대/거래 삭제 제한, 거래 등록/수정·예산 관리 허용.
- 제거된 구성원 접근/쓰기 차단, 보관 계정 신규 분개 차단.
- 관리자 직접 빈 transaction 삽입도 deferred constraint가 거부.
- 서로 다른 두 세션이 동일 초대를 동시에 수락하면 한 명만 성공, 총 2명 유지.

## 브라우저 검증 범위

테스트 소스: `tests/browser/ledger.spec.ts`. 실제 렌더링된 Nuxt 앱을 Chromium으로 조작합니다. 테스트 네트워크 응답은 Playwright에서만 주입합니다.

- 로그인 → 새 가계부 → 초기 자산/부채 → 5건 거래 입력.
- 대시보드 순자산 17,430,000원, 월 지출 70,000원 확인.
- 새로고침 후 재조회, 상위 식비 예산 600,000원과 사용 70,000원/잔여 530,000원.
- 거래 상세 수정/삭제, 직접분개 불균형 오류 후 정상 저장.
- 계정 생성/보관 및 보관된 계정 표시.
- 3개 보고서 화면, 초대코드 발급, 로그아웃.
- 데스크톱 1440px / 모바일 390px 화면과 가로 넘침 검사.
- 보호된 URL 로그인 전 이동, 가입 확인 안내, 잘못된 로그인 오류, 월 입력 비움 처리.
- 브라우저 런타임 pageerror 확인.

화면 파일 `dashboard-desktop.png`, `dashboard-mobile.png`는 검증용 가상 데이터 화면이며 실제 연결된 가계부가 아닙니다.

## 발견 후 수정한 문제

1. 기초잔액 RPC에서 PL/pgSQL 변수와 JSON 별칭 충돌 → 별칭 분리 후 DB 재검증.
2. option 닫힘 오류 → 수정 후 타입/빌드 재검증.
3. 가계부 미생성 화면에서 NuxtPage 조건부 제거로 최초 라우팅이 실행되지 않음 → 표준 NuxtLayout/NuxtPage로 분리.
4. 다중 문장 인라인 이벤트의 포매팅 오류 → 명시적 핸들러로 추출.
5. 계정/인증 전환 중 늦게 도착한 응답과 loading 초기화 → 사용자·가계부·요청 세대 확인 및 초기화.
6. 기본 금액 단위 표시와 모바일 제목 줄바꿈 보완. 차트 캡처는 전환 종료 상태로 저장.

## 미실행 / 환경 미제공

- 실제 Supabase Auth 이메일 발송·인증·토큰 만료·갱신과 실제 PostgREST 통합.
- 실제 두 사람 계정으로 원격 공동 사용. 로컬 DB의 역할·동시성은 위와 같이 검증.
- Vercel 실제 배포 및 Supabase 운영 migration 적용.
- 대용량 원장 부하 테스트와 장기 운영 테스트.

**판정:** 로컬 구현 및 명시한 로컬 검증 완료. 실제 운영 연결 승인/검증을 뜻하지 않습니다. Supabase 프로젝트에 migration과 공개 환경변수를 적용한 뒤 실제 이메일 가입과 두 사용자 흐름을 확인해야 합니다.

최종 화면은 데스크톱·모바일 PNG를 직접 열어 금액 단위, 차트, 표, 제목 줄바꿈과 잘림 여부를 확인했습니다.
