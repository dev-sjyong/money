# 고정지출 항목 삭제

## Plan / Do
등록 항목 관리에서 삭제 확인 후 항목을 모든 월의 목록·예정액에서 제외한다. 납부 거래와 연결 이력은 DB에 보존하고 이미 연결된 거래의 중복 사용을 계속 막는다. 미래 월만 중단하려는 경우 기존 규칙 수정 기능을 사용한다. 삭제는 revision 검증과 가계부 권한 검사를 거친다. 삭제 후 저장·납부·연결·건너뛰기·취소는 서버에서 차단한다.

## 적용
Supabase SQL Editor에서 001~005 적용 후 `202610010006_delete_fixed_expenses.sql`을 한 번 실행하고 PR을 병합한다. 삭제한 항목을 화면에서 복구하는 기능은 포함하지 않는다.

## Check
- 타입 검사·프로덕션 빌드 통과.
- 로컬 PostgreSQL에서 신규 삭제 검사 14개 + 기존 고정지출 검사 38개, 총 52개 통과. 권한, revision, 거래 보존, 연결 예약 보존, 삭제 이후 변경·납부 차단과 롤백을 확인했다.
- HTTP 모의 Supabase 브라우저 시나리오 6개 통과. 삭제 확인창 안내·취소·확정·새로고침 후 유지 및 기존 거래·통계·일정 기능을 검증했다.
- 운영 Supabase와 실제 인증·이메일은 변경하거나 검증하지 않았다.
