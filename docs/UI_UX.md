# UI/UX 개선 계획

## Plan
기존 초록색 브랜드와 회계 동작을 유지한다. 모바일 가로 스크롤 메뉴를 주요 화면 하단 탐색과 펼칠 수 있는 전체 메뉴로 대체한다. 데스크톱 메뉴는 일상 기록·지출 계획·통계·설정으로 묶는다. 현재 위치, 키보드 탐색, 숫자와 보조 문구의 가독성을 개선한다.

## Do
레이아웃과 공통 스타일만 변경한다. 전체 메뉴는 모달이 아닌 문서 내 펼침 영역으로 제공하고 이동·Escape 시 닫는다. 데이터와 인증 로직은 유지한다.

## Check
타입 검사·빌드·기존 브라우저 시나리오 및 모바일 메뉴 열기/이동/닫기·320px 너비를 확인한다. HTTP 모의 Supabase를 사용하며 운영 인증 검증과 구분한다.

## Check 결과
- `npm run typecheck`: 통과.
- `npm run build`: 통과.
- `npm run test:ui`: 5개 시나리오 통과. 모바일 전체 메뉴 열기, Escape 닫기 및 포커스 복귀, 월 예산 이동 후 메뉴 닫기를 추가 검증했다. 기존 320px/390px 화면 너비 검증도 통과했다.
- 데스크톱 및 모바일 대시보드 캡처를 직접 확인했다. 기존 기능별 화면 캡처도 새 레이아웃으로 갱신했다.
- 첫 브라우저 실행은 재빌드 전 서버가 이전 자산을 참조하여 로그인 화면 로드에 실패했다. 서버 재시작 후 모든 시나리오가 통과했다.
- 실제 Supabase 인증·이메일 및 운영 데이터는 검증하지 않았다. DB 변경이 없어 SQL 추가 적용은 필요하지 않다.

## Act
GitHub PR에서 검토 후 병합하면 연결된 Vercel 배포에 반영할 수 있다. 운영 배포 후 실제 휴대폰에서 하단 안전 영역과 입력 키보드 동작을 확인한다.
