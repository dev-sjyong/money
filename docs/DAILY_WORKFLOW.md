# 남은 사용성 개선

## Plan
2. 즐겨찾는 거래 복사와 유형별 최근 계정 기억.
4. 동일 날짜·계정·금액의 중복 후보를 저장 전 확인. 고정지출 미처리·개인회생 남은 납부는 월 점검과 연결.
5. 기록자·계정(하위 포함)·금액 범위·기간·검색어 필터와 조건 저장.
6. 월별 수입·지출, 납부 점검, 중복 후보, 통장·현금 실제 잔액 대조 및 점검 완료 표시.

개인 설정은 사용자·가계부별 현재 브라우저에 저장한다. 다른 기기와 동기화하지 않는다. 월 점검 완료는 거래를 잠그거나 장부를 수정하지 않으며, 관련 장부가 바뀌면 다시 점검하도록 표시한다. 월말 잔액은 부모 계정과 자식 계정을 합산해 중복하지 않고 각 계정의 직접 분개 잔액을 대조한다.

## Do / 사용 방법
- 거래 목록의 ☆를 눌러 즐겨찾기를 추가하고 거래 기록 화면에서 바로 입력한다. 최대 20개이며 날짜는 오늘로 복사한다. 삭제·수정된 원본과 별개의 저장된 입력 양식이다. 보관된 계정은 저장 전 변경해야 한다.
- 간편 거래 유형별 마지막 지출/결제 계정 등을 다음 입력에 복원한다. 날짜와 금액은 자동으로 재사용하지 않는다.
- 같은 날짜·전체 계정·금액의 거래가 있으면 저장을 멈추고 기존 거래 링크를 보여준다. 정상적으로 여러 번 발생한 거래는 ‘확인하고 별도 거래 저장’으로 계속할 수 있다. 서버 동시 요청에서 발생한 중복까지 강제 차단하는 기능은 아니다.
- 거래 내역의 상세 검색에서 기록자·계정(하위 계정 포함)·차변 합계 금액 범위를 선택한다. 검색 조건은 최대 10개이며 같은 이름으로 저장하면 교체한다.
- 통계와 보고서의 ‘월 마감 점검’에서 월을 선택한다. 미처리 고정지출·변제금, 연결 거래 확인 필요, 중복 후보를 확인하고 자산 계정별 실제 월말 잔액을 입력한다. 장부와 차이가 있으면 거래와 초기 잔액을 정정한다. 금액은 직접 분개 잔액이며 부모·자식 계정 금액을 중복 입력하지 않는다.
- 지난달 이전 월에서 납부가 모두 처리되고 잔액 차이가 없어지면 중복·누락 확인 후 완료 표시를 저장한다. 완료 표시가 있어도 거래 편집을 막지 않는다. 이전 거래나 일정이 바뀌면 다시 점검하라는 안내를 표시한다.

## Act / 적용
PR을 병합하면 연결된 Vercel 배포로 반영한다. 별도 SQL이 필요하지 않다. 즐겨찾기·최근 계정·조건·월 점검 표시는 현재 브라우저에서만 유지되며 배우자의 브라우저나 다른 기기에는 공유되지 않는다. 브라우저 데이터를 삭제하면 개인 설정도 사라지며 실제 가계부 거래에는 영향을 주지 않는다.
